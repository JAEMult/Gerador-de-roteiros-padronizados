Gerador de Roteiros Padronizados

Envie planilhas ou arquivos de texto e deixe uma IA extrair narração, prompts e demais campos sempre no mesmo formato.

⚙ CONFIGURAÇÃO DA IA

Nenhuma chave salva.
Sua chave fica salva apenas neste navegador (localStorage) e é usada somente para chamar a API do provedor escolhido. A última IA, chave e modelo usados ficam salvos como padrão. Chave grátis do Gemini: aistudio.google.com/apikey — Chave grátis do Groq: console.groq.com/keys

Documentos grandes ou com vários idiomas costumam ultrapassar o limite gratuito do Groq (12.000 tokens/minuto). Para esses casos, prefira o Gemini, que tem um limite bem maior. Se a IA recusar o modelo por estar desatualizado, confira o nome atual em ai.google.dev/gemini-api/docs/models (Gemini) ou console.groq.com/docs/models (Groq) e cole o nome certo no campo Modelo acima.

🐙 BACKUP NO GITHUB

Opcional — só necessário se você for usar o botão "Salvar Backup no GitHub" no topo da página. Abrir e atualizar o app não precisa de nada disso. Cole aqui um token do GitHub (permissão de leitura/escrita só no repositório Gerador-de-roteiros-padronizados); fica salvo apenas neste navegador.
